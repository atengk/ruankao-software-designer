# 0006 上午题排版视觉规范与检索式自测交互演进

## 背景与上下文

在上午综合知识知识库第一阶段骨架搭建完成后，全学科 9 大模块共 25 篇考点精要、全科公式速查手册及避坑秒杀清单已形成基础文本。然而在实际备考与自测体验中，暴露出若干影响学习效率与阅读质感的工程痛点：
1. **答案剧透破坏主动召回**：历年典型机考真题的答案与逐项排错解析直接紧随题干平铺展示，考生在刷题时视线极易提前扫到答案，无法形成高质量的主动检索与思维对抗（Active Recall）；
2. **文本图表表达力不足**：系统架构、进程状态迁移、网络协议栈与数字信封等复杂流转过程仅采用简陋的 ASCII 字符画展示，在移动端排版容易溢出且视觉表现力较弱；
3. **元数据与容器样式割裂**：顶部所属模块与题号仍采用无序列表文本，部分警示与避坑使用非标准引用块，未充分发挥 VitePress 原生生态组件的表现力；
4. **孤岛效应与单向链接**：横向的《公式速查手册》及《避坑秒杀库》与各学科纵向的深度考点精要之间缺乏互通闭环，考生在速查时难以快速穿透到底层推导与机考例题。

为打造工业级专业知识库并提升 2026 年考生的备考通关效率，特制定本次排版视觉规范与自测交互演进决策。

---

## 架构决策

1. **统一顶部组件化元数据标签流 (`<Badge>`)**：
   - 全量考点精要顶部统一引入 VitePress 内置 `<Badge />` 组件；
   - 规范采用三种类型分流呈现：`所属模块 (type="info")`、`考查题号 (type="tip")`、`重要程度 (type="danger" 或 "warning")`，实现视线首屏结构化对齐。

2. **容器语法标准化与语义化收敛**：
   - 彻底废弃普通引用块模拟警告的做法，全面迁移至 VitePress 官方原生容器语法；
   - 通关指引统一收敛为 `::: tip 🎯 45 分及格通关指引`；
   - 命题陷阱统一收敛为 `::: danger 🚨 常见命题陷阱盘点`，强化视觉层级警示。

3. **引入防剧透检索式自测折叠体系 (Active Recall Drill)**：
   - 所有真题与例题的【正确答案】、【核心切入点】与【逐项排错剖析】统一封装进原生折叠容器：
     `::: details 💡 点击展开【正确答案与逐项排错剖析】`；
   - 默认折叠收起，考生必须在脑海中完成独立审题、排除与作答后，再手动展开复盘，形成记忆强化闭环。

4. **全面落地自适应 Mermaid 矢量图表**：
   - 剔除存量文档中的 ASCII 伪图表，针对考点特性全面引入高清 Mermaid 矢量拓扑：
     - 状态演进采用 `stateDiagram-v2`（如三态/五态进程模型）；
     - 双向保密通信与握手时序采用 `sequenceDiagram`（如数字签名与数字信封混合密码）；
     - 关系与实体依赖采用 `erDiagram`（如数据库实体联系模型）；
     - 知识网络与决策树采用 `flowchart TD/LR`（如著作权争议确权判定、IPv4 地址结构、Cache 映射架构等）。

5. **构建全科网状双向穿透互链闭环 (Bilateral Anchor Traversal)**：
   - 在《全科计算公式速查手册》中，为每个公式条目增补直达 25 篇考点精要深度推导与例题的相对路径链接；
   - 在《全科高频避坑清单与秒杀模板库》中，为 22 个出题人陷阱与 16 个秒杀模板增补直达考点精要与公式手册的双向穿透链接；
   - 在全量 25 篇考点精要文末统一注入标准【考点通关与速查导航】模块，直达横向速查表与备考大纲。

6. **确立清晰透明的两阶段备考演进看板 (Phase Roadmap)**：
   - 在 README 与首页显式标定：
     - **阶段一：上午综合知识全科（已达成 100%）**；
     - **阶段二：下午应用技术与 Java 实战双轨演练（规划演进中）**；
   - 明确边界，合理引导读者复习节奏。

---

## 预期影响与收益

- **自测效果飞跃**：防剧透折叠有效激发考生主动记忆与独立解题，排错剖析提升审题抗干扰能力；
- **视觉排版现代化**：Mermaid 矢量图随暗色/亮色主题自适应渲染，全站排版更具呼吸感与工程质感；
- **网状索引互通**：横向速查手册与纵向深度考点任意穿透，大幅缩短考前 72 小时查漏补缺的检索路径；
- **构建稳健零死链**：全站所有超链接经过 VitePress 生产构建校验，零死链、零警告。
