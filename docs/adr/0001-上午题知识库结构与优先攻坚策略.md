# 0001 上午题知识库模块化划分与投产比优先攻坚策略

## 背景与上下文

2026年下半年软考中级软件设计师备考涉及广泛的基础知识与专业实操，其中上午题涵盖 75 道单项选择题，考点分散且繁杂。备考过程面临“知识点零散易忘、与下午主观题割裂、盲目平均用力”的风险。我们需要确立知识库目录结构、考点沉淀颗粒度以及科目攻坚的先后次序。

## 架构决策

1. **目录结构采用学科模块化隔离**：统一在 `knowledge/am-general/` 下按 8 大考纲技术领域独立建档管理，避免按题号或流水账堆叠。
2. **考点精要遵循工业级四要素模板**：每个考点闭环包含“核心考纲与概念辨析”、“计算公式与分析模型”、“命题题眼与陷阱防御”、“历年典型真题溯源与验证”。
3. **实行投产比优先的梯队攻坚策略**：
   - 第一梯队优先突破与下午题强绑定的“面向对象与设计模式”、“软件工程”、“数据结构与算法”；
   - 第二梯队推进“操作系统”与“数据库系统”；
   - 第三梯队推进“计算机体系结构”与“网络安全”；
   - 第四梯队考前速记“知识产权法规”与“专业英语”。
4. **双轨驱动（文档 + 可运行源码）**：在 `src/` 建立工程化源码目录，对核心设计模式与重点算法进行单元测试与可运行代码验证，彻底消除下午代码填空盲区。

## 预期影响与权衡

- **优势**：知识库索引清晰，上午选择题与下午大题产生高强度知识复用，备考投产比最大化。
- **代价**：相比纯记笔记，前期需要投入一定精力搭建源码测试框架，但显著降低后期下午题专项复习的重学成本。
