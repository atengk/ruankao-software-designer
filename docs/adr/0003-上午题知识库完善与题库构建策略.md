# 0003 上午题知识库完善与题库构建策略

## 背景与上下文

在完成上午综合知识 9 大学科 22 篇基础考点精要知识库搭建后，进入备考深化与题库演练阶段。上午客观选择题（75分）具有考点碎片化、干扰项迷惑性强、计算推导容易混淆的特征。传统备考常常陷入“单纯做整套卷对答案，知其然不知其所以然”的误区。需要确定下一阶段上午题优化的核心发力点、真题题库组织形态以及计算题沉淀方式。

## 架构决策

1. **核心发力点聚焦“高频考点深挖 + 易错陷阱增补 + 新法新规渗透”**：
   - 保持现有 22 篇考点精要骨架，不盲目横向铺开冷门低频考点；
   - 重点增补近年来机考强化考查的法律法规（《个人信息保护法》、等保 2.0）、现代敏捷过程与云原生微服务术语；
   - 在各精要文档中深度挖掘易混淆概念与命题陷阱防御。

2. **真题题库采用“考点精要嵌入 + 逐项排错解析”规范**：
   - 历年典型真题优先嵌入对应考点精要的第四要素（“典型真题切入验证”），实现“学理论 $\to$ 破真题”即时闭环；
   - 严格执行**逐项排错解析（Distractor Analysis）**标准：除正确答案解析外，必须对每一个错误选项/干扰项详细阐明错误机理、混淆点与反例，杜绝单纯给答案；
   - 配套采用本地 Markdown 工单（`.scratch/am-general/`）跟踪练习与错题归纳。

3. **集中独立建立《上午综合知识高频计算公式与速解模板速查表》**：
   - 将计算机体系结构、操作系统、软件工程、网络等学科的全部数值计算公式统一汇总至独立索引文档；
   - 明确每个参数的物理意义、速算口诀与极值边界条件，赋能冲刺阶段的高效背诵。

## 预期影响与权衡

- **优势**：显著提升知识点吸收与防坑能力，逐项排错使每一道真题的复习价值放大 4 倍，集中公式表彻底消除考前参数混淆。
- **代价**：相比单纯录入题目的题库，编写逐项排错解析与公式推导的工作量较大，但能彻底打通题眼本质，极大提升一次性通过率。
