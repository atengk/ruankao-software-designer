# 分诊标签与角色映射

工程技能通过五个标准分诊角色协同推进。本文档定义各标准角色在本项目任务跟踪器中的对应标签。

| 标准技能角色 | 本项目对应标签 | 业务含义 |
| :--- | :--- | :--- |
| `needs-triage` | `needs-triage` | 待分诊：需要评估并确定该考点/任务的处理策略 |
| `needs-info` | `needs-info` | 待补充：考点背景或输入信息不完整，等待补充材料 |
| `ready-for-agent` | `ready-for-agent` | 代理就绪：规格与考点解析明确，可由 AI 代理自主拆解或生成 |
| `ready-for-human` | `ready-for-human` | 人工介入：需要考生本人背诵记忆、亲笔答题或深度决策 |
| `wontfix` | `wontfix` | 暂不处理：超出软件设计师考纲范围或非重点考点 |

当技能提及某一角色（如“打上代理就绪分诊标签”）时，统一使用上表对应的标签字符串。
