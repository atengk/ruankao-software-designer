## 核心方法论大纲

1. **E-R 向关系模式转换三大铁律**：
   - $1:1$ 联系：可独立成表，或将任一方主键并入另一方充当外键；
   - $1:N$ 联系：强制将 1 端主键并入 N 端关系模式作为外键；
   - $M:N$ 联系：强制独立建立新表，两端实体主键构成联合复合主键。
2. **主键与外键推导法**：最小候选键覆盖与参照完整性约束。
3. **规范化理论快速判别**：消除非主属性部分函数依赖达 2NF，消除非主属性传递函数依赖达 3NF。
