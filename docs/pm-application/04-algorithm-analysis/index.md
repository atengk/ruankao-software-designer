## 核心方法论大纲

1. **四大宗门特征判别表**：
   - 动态规划 (DP)：重叠子问题、最优子结构、二维数组 `dp[][]` 填表找状态转移；
   - 贪心算法 (Greedy)：局部最优决策、排序后单向遍历；
   - 分治法 (Divide & Conquer)：独立子问题折半两路递归与合并；
   - 回溯法 (Backtracking)：深度优先搜索、约束剪枝、恢复现场。
2. **时空复杂度速判**：递归树规模分析与主定理 (Master Theorem)。
3. **代码填空抢分套路**：必拿第 1 问算法策略与复杂度（4分），攻克循环初始值与递归出口（4分），理智取舍末尾高难指针。
