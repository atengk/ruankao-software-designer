## 核心方法论大纲

1. **外部实体识别法则**：题干角色定位、边界判定、主谓语主语提取。
2. **数据存储识别法则**：存储名词定位、读写对称性、双存储直连违规。
3. **缺失数据流补全三大法则**：
   - 父子图平衡四查法（边界流守恒）；
   - 黑洞排查（只进不出）；
   - 奇迹排查（只出不进）；
   - 灰洞排查（输入不足以产出输出）。
4. **数据字典定义符号**：`=`（定义为）、`+`（与/连接）、`[|]`（或/选择）、`{}`（重复）、`()`（可选）。
