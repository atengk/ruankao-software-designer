## 一、 核心考纲与概念辨析

### 1. 二叉树五大核心数学定理（必背计算公式）

1. **第 $i$ 层的最大节点数**：二叉树第 $i$ 层上最多有 $2^{i-1}$ 个节点 ($i \ge 1$)。
2. **深度为 $k$ 的最大节点数**：深度为 $k$ 的二叉树最多有 $2^k - 1$ 个节点 ($k \ge 1$)（即满二叉树）。
3. **叶子节点与度为 2 节点的关系定理（绝密高频秒杀题）**：
   对任何一棵二叉树，如果其叶子节点数（度为 0 的节点）为 $n_0$，度为 2 的节点数为 $n_2$，则必定满足：
   $$n_0 = n_2 + 1$$
   *(推导基石：总边数 $B = n - 1 = n_1 + 2n_2$，总节点数 $n = n_0 + n_1 + n_2$，联立立得)*。
4. **完全二叉树的深度**：具有 $n$ 个节点的完全二叉树深度为 $\lfloor \log_2 n \rfloor + 1$ 或 $\lceil \log_2 (n+1) \rceil$。
5. **完全二叉树的父子序号映射（从 1 开始编号）**：
   - 节点 $i$ 的双亲节点为 $\lfloor i/2 \rfloor$（若 $i=1$ 则为根，无双亲）；
   - 左孩子节点为 $2i$（若 $2i > n$ 则无左孩子）；
   - 右孩子节点为 $2i+1$（若 $2i+1 > n$ 则无右孩子）。

---

### 2. 二叉树的四种遍历序列与唯一确定定理

| 遍历方式 | 访问次序 | 递归本质 |
| :--- | :--- | :--- |
| **先序遍历 (Preorder)** | **根 $\rightarrow$ 左子树 $\rightarrow$ 右子树** | 访问到的第一个节点必为整棵树的**根节点** |
| **中序遍历 (Inorder)** | **左子树 $\rightarrow$ 根 $\rightarrow$ 右子树** | 根节点在中间，左侧全部为**左子树**节点，右侧全部为**右子树**节点 |
| **后序遍历 (Postorder)**| **左子树 $\rightarrow$ 右子树 $\rightarrow$ 根** | 访问到的最后一个节点必为整棵树的**根节点** |
| **层序遍历 (Levelorder)**| 从上至下、从左至右逐层遍历 | 借助**队列 (Queue)** 辅助实现广度搜索 |

> [!IMPORTANT]
> **唯一还原二叉树树形结构的条件**：
> - **先序序列 + 中序序列** $\rightarrow$ **能够唯一确定**一棵二叉树；
> - **后序序列 + 中序序列** $\rightarrow$ **能够唯一确定**一棵二叉树；
> - **层序序列 + 中序序列** $\rightarrow$ **能够唯一确定**一棵二叉树；
> - **先序序列 + 后序序列** $\rightarrow$ **❌ 无法唯一确定**二叉树！必须包含**中序序列**以区分左右子树界限！

### 3. 最优二叉树（哈夫曼树 Huffman Tree）构造与 WPL 计算

- **带权路径长度 (WPL, Weighted Path Length)**：树中所有叶子节点的权值与该节点到根节点的路径长度（即边数）的乘积之和：
  $$WPL = \sum_{k=1}^{n} w_k \cdot l_k$$
- **哈夫曼树核心性质**：
  1. 给定 $n$ 个叶子节点，构造出的哈夫曼树共有 **$2n - 1$ 个节点**（没有度为 1 的分支节点，$n_1 = 0$）；
  2. 权值越大的叶子节点离根节点越近，权值越小的叶子节点离根节点越远。
- **哈夫曼构造算法步骤**：
  1. 从权值森林中选取**权值最小的两个根节点**作为左右孩子；
  2. 生成一个新的父节点，其权值为两孩子权值之和；
  3. 将两原节点从森林中移出，将新父节点放入森林；
  4. 重复上述步骤，直至森林中只剩一棵根树。
- **哈夫曼编码**：规定左分支标记 `0`，右分支标记 `1`。由于任何叶子节点不可能在其他叶子节点的路径上，因此生成的编码是无二义性的**前缀编码（Prefix Code）**。

## 二、 命题题眼与陷阱防御

> [!CAUTION]
> ### 🚨 常见命题陷阱盘点
> 1. **度数计算陷阱**：
>    - 题目给出“度为 1 的节点数 $n_1$ 为 3，度为 2 的节点数 $n_2$ 为 5，求总节点数”。很多考生乱套公式，牢记 $n_0 = n_2 + 1 = 6$，总节点数 $n = n_0 + n_1 + n_2 = 6 + 3 + 5 = 14$！
> 2. **线索二叉树的空指针线索化**：
>    - $n$ 个节点的二叉树共有 $2n$ 个指针域，其中只有 $n-1$ 条实边指向孩子，因此正好有 **$n+1$ 个空指针域**可以用来存放前驱和后继线索！
> 3. **哈夫曼树总结点数速判**：
>    - 若有 8 个权值叶子节点，生成的哈夫曼树总结点数直接为 $2 \times 8 - 1 = 15$ 个节点，其中非叶子节点数必为 $n - 1 = 7$。

## 三、 典型真题溯源与验证

### 【真题精选 1】（考查叶子节点定理）
**题干**：一棵包含 101 个节点的完全二叉树，其中度为 2 的节点个数为（ ）。
A. 49  
B. 50  
C. 51  
D. 52  

**【答案】**：**B**  
**【解析】**：
设完全二叉树的叶子数为 $n_0$，度为 1 的节点数为 $n_1$，度为 2 的节点数为 $n_2$。
总节点数 $n = n_0 + n_1 + n_2 = 101$。
根据二叉树基本定理：$n_0 = n_2 + 1$。
代入得：$(n_2 + 1) + n_1 + n_2 = 2n_2 + n_1 + 1 = 101$，即 $2n_2 + n_1 = 100$。
由于在完全二叉树中，度为 1 的节点 $n_1$ 只能为 0 或 1：
- 若 $n_1 = 1$，则 $2n_2 = 99$（无整数解，舍去）；
- 故必有 $n_1 = 0$，解得 $2n_2 = 100 \implies n_2 = 50$。故选 B。

### 【真题精选 2】（考查前中后序还原树结构）
**题干**：某二叉树的先序遍历序列为 `A B D E C F`，中序遍历序列为 `D B E A F C`，则该二叉树的后序遍历序列为（ ）。
A. D E B F C A  
B. D E B C F A  
C. E D B F C A  
D. D B E F C A  

**【答案】**：**A**  
**【解析】**：
1. 由先序遍历第一个元素可知，根节点为 **A**；
2. 对应中序遍历中，以 A 为界划分为左右两半：左子树节点集合为 `{D, B, E}`，右子树节点集合为 `{F, C}`；
3. 左子树先序为 `B D E`，中序为 `D B E` $\implies$ B 为左子树根，D 为 B 的左孩子，E 为 B 的右孩子；
4. 右子树先序为 `C F`，中序为 `F C` $\implies$ C 为右子树根，F 为 C 的左孩子；
5. 后序遍历（左-右-根）：左子树后序为 `D E B`，右子树后序为 `F C`，最后访问根 A，拼接后为 `D E B F C A`。选 A。
