## 一、 核心考纲与概念辨析

### 1. CPU 核心部件归属对比（运算器 vs 控制器）

计算机硬件中央处理器（CPU）由运算器、控制器和内部寄存器组构成：

| CPU 部件类别 | 核心部件名称 | 英文缩写 | 核心功能与工作机制 |
| :--- | :--- | :--- | :--- |
| **运算器**<br>(执行数据加工) | **算术逻辑单元** | **ALU** | 负责执行所有算术运算（加减乘除）和逻辑运算（与或非异或） |
| | **累加寄存器** | **AC** | 暂存算术逻辑运算的操作数或运算结果，为 ALU 提供临时输入 |
| | **数据缓冲寄存器** | **DR** | 暂存由内存读出或写入内存的数据字 |
| | **状态条件寄存器** | **PSW** | 记录程序运行时的状态标志（如零标志 Z、溢出标志 V、符号标志 N、进位标志 C） |
| **控制器**<br>(发出控制节拍) | **程序计数器** | **PC** | **存放下一条要执行指令的内存地址**，具有自动自增计数功能 |
| | **指令寄存器** | **IR** | **存放当前正在执行的指令**，供指令译码器分析 |
| | **指令译码器** | **ID** | 对指令寄存器中的**操作码**进行分析解释，产生对应的微操作控制信号 |
| | **地址寄存器** | **AR** | 保存当前 CPU 正在访问的内存物理单元地址 |
| | **时序部件与脉冲发生器**| / | 产生计算机工作所需的微节拍时钟脉冲，协调各部件同步工作 |

> [!IMPORTANT]
> **软考必杀题眼**：
> - 存放“下一条指令地址”的是 **程序计数器 (PC)**；
> - 存放“当前正在执行指令”的是 **指令寄存器 (IR)**；
> - 运算器中负责暂存中间计算结果的是 **累加寄存器 (AC)**。

### 2. CISC (复杂指令集) vs RISC (精简指令集) 全景对比

| 对比维度 | CISC (Complex Instruction Set Computer) | RISC (Reduced Instruction Set Computer) |
| :--- | :--- | :--- |
| **指令数量与复杂度** | **指令数量庞大（几百条）**，指令功能复杂多样 | **指令数量精炼（几十条）**，只保留使用频度最高的简单指令 |
| **指令长度** | **指令字长不固定**，寻址方式极其繁多（十几种） | **指令字长固定（等长）**，寻址方式极少（通常 2~3 种） |
| **执行周期** | 大多数指令需要多个时钟周期才能完成 | **绝大多数指令在一个时钟周期内完成（单周期）** |
| **访存限制** | 大量指令允许直接访问内存（计算与访存混杂） | **严格限制访存指令，只有 LOAD（读）和 STORE（写）指令可以访问内存**，其余运算均在寄存器间进行 |
| **通用寄存器** | 寄存器数量相对较少 | **配置大量通用寄存器**，充分利用寄存器减少访存开销 |
| **控制器实现** | **微程序控制器 (Microprogrammed)** | **硬布线组合逻辑控制器 (Hardwired)**（速度极快） |
| **流水线支持** | 难以实现高效流水线 | **极其便于实现超标量与指令级流水线** |

### 3. Flynn 计算机体系结构分类法

依据**指令流 (Instruction Stream)** 和 **数据流 (Data Stream)** 的单重/多重性划分：

| 体系结构类别 | 英文缩写 | 核心特征与系统形态 | 现实计算机实例 |
| :--- | :--- | :--- | :--- |
| **单指令流单数据流** | **SISD** | 传统的单 CPU 顺序执行计算机，一个控制部件对应一个运算器 | 传统单核冯·诺依曼计算机 |
| **单指令流多数据流** | **SIMD** | 一个控制部件控制**多个并行处理单元**，同步执行相同指令处理不同数据 | **向量处理机、阵列处理机、GPU 图像图形处理器** |
| **多指令流单数据流** | **MISD** | 理论模型，多个控制部件对同一数据流操作，**工程上极少使用或不存在** | 容错系统中的多机热备表决（近似） |
| **多指令流多数据流** | **MIMD** | 多个独立的 CPU 独立执行各自不同的指令流，处理各自的数据流 | **现代多核多处理器、分布式集群、超级计算机** |

## 二、 命题题眼与陷阱防御

> [!CAUTION]
> ### 🚨 常见命题陷阱盘点
> 1. **PC 与 IR 的功能颠倒**：
>    - 题目问“CPU 在执行指令过程中，用来存放当前指令执行地址的部件是（ ）”，答案必为 **PC（程序计数器）**；若问“用来存放当前正在执行指令内容的部件是（ ）”，答案为 **IR（指令寄存器）**。
> 2. **RISC 的访存特征**：
>    - 试题选项常设坑：“RISC 允许加法指令直接对内存地址中的数据进行相加并写回” $\rightarrow$ **绝对错误**！RISC 规定必须先通过 `LOAD` 将数据读入寄存器，在寄存器中完成加法后，再通过 `STORE` 写入内存。
> 3. **硬布线 vs 微程序**：
>    - RISC 采用**硬布线逻辑（组合逻辑电路）**，因此速度快、芯片面积小；CISC 采用**微程序技术（存储在 ROM 中的微指令）**。

## 三、 典型真题溯源与验证

### 【真题精选 1】（考查 RISC 与 CISC 架构差异）
**题干**：精简指令集计算机（RISC）采用了许多优化设计技术，与复杂指令集计算机（CISC）相比，下列叙述中不属于 RISC 特征的是（ ）。
A. 大多数指令在一个机器周期内完成  
B. 优先采用硬布线逻辑实现控制器  
C. 寻址方式丰富，指令字长不固定  
D. 仅通过 LOAD 和 STORE 指令访问内存  

**【答案】**：**C**  
**【解析】**：
RISC（精简指令系统）的核心设计理念是简化指令系统以提高流水线效率，其指令格式规整、指令字长严格固定、寻址方式极少（通常仅提供寄存器寻址、立即数寻址和基址寻址等少数几种）。而“寻址方式丰富、指令字长不固定”是典型的 **CISC（复杂指令系统）** 特征。故 C 选项不属于 RISC 特征。
