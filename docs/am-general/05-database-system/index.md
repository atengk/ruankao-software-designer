# MOD-05 数据库系统知识专题

- **考纲地位**：综合知识必考 5 ~ 6 分（48 ~ 53 题），直接支撑下午应用技术 15 分（第 2 题 数据库设计 E-R 与 SQL）
- **梯队归属**：第二梯队（数据建模与规范化核心）

## 考点精要清单

1. [01-ER模型向关系模式转换与关系代数.md](./01-ER模型向关系模式转换与关系代数.md)
   - 1:1、1:N、M:N 联系向关系模式转换三大黄金法则
   - 最少关系模式数计算（实体数 + M:N 联系数）
   - 关系代数 5 大专门运算（选择 $\sigma$、投影 $\pi$、自然连接 $\bowtie$、等值连接、除运算 $\div$）
2. [02-规范化理论函数依赖与范式判定.md](./02-规范化理论函数依赖与范式判定.md)
   - 完全、部分、传递函数依赖定义辨析
   - 候选码图解四类属性（L, R, LR, N）秒杀求解法
   - 1NF $\rightarrow$ 2NF $\rightarrow$ 3NF $\rightarrow$ BCNF 范式阶梯判定（单属性主键秒杀 2NF、消除传递依赖判定 3NF）
   - 模式分解无损连接与保持函数依赖
3. [03-事务ACID特性与并发控制封锁协议.md](./03-事务ACID特性与并发控制封锁协议.md)
   - ACID 四大特性与底层支撑机制（Undo Log、Redo Log、锁）
   - 三大并发异常（丢失修改、读脏数据、不可重复读）
   - 三级封锁协议释放时机与防御边界
   - 两段锁协议 (2PL) 可串行化定理与死锁可能性
