## 一、 核心考纲与概念辨析

### 1. E-R 图向关系模式转换三大黄金规则（贯通下午题 2）

| 实体间联系类型 | 关系模式转换策略 | 主键 (PK) 与外键 (FK) 设定规则 | 转换后模式数量 |
| :--- | :--- | :--- | :--- |
| **1 : 1 联系**<br>(一对一，如校长与学校) | **方法 A（合并入任一端）**：将联系与任意一端的实体关系模式合并<br>**方法 B（独立建表）**：单独建立一个关系模式 | - 若合并：将另一端实体的主键引入作为**外键**，并加入联系自身属性<br>- 若独立：两端主键均可作为候选码 | 合并为 **2 个**模式，或独立为 3 个模式 |
| **1 : N 联系**<br>(一对多，如部门与员工) | **推荐合并入 N 端 (多端)**；也可以单独建立独立关系模式 | **将 1 端实体的主键引入到 N 端实体作为外键**，并将联系的属性也加入到 N 端实体中 | 通常转换为 **2 个**关系模式 |
| **M : N 联系**<br>(多对多，如学生与课程) | **必须单独建立一个独立的关系模式**（绝对不能合并入任何一方！） | **新模式的主键为两端实体主键的联合组合键**；两端主键在新模式中分别作为外键 | **必须转换为 3 个**关系模式（2实体表 + 1联系表） |
| **多元联系 / 自反联系**<br>(如三元联系、领导与员工) | 类似处理：若包含多对多联系，**必须独立转换为一个关系模式** | 独立模式的主键为各参与实体主键的组合 | 独立建表 |

### 2. 关系代数五大专门运算辨析

| 运算符号 | 运算名称 | 运算本质与过滤维度 | 核心语法与数学定义 |
| :--- | :--- | :--- | :--- |
| **$\sigma$** | **选择运算 (Select)** | **按行过滤（水平切分）**：挑选满足指定逻辑条件的元组 | $\sigma_{\text{条件}}(R)$，如 $\sigma_{\text{Age} > 20}(\text{Student})$ |
| **$\pi$** | **投影运算 (Project)** | **按列过滤（垂直切分）**：挑选指定的属性列，并**自动去除重复行** | $\pi_{\text{列名}}(R)$，如 $\pi_{\text{Name, Age}}(\text{Student})$ |
| **$\bowtie$** | **自然连接 (Natural Join)** | 先做广度笛卡尔积，再挑选**同名公共属性值相等**的行，并**在结果中去除重复的同名属性列** | 最常用的连接方式，结果属性数为 $R + S - \text{同名列数}$ |
| **$\underset{F}{\bowtie}$** | **等值连接 (Equi-Join)** | 满足某条件（如 $R.A = S.B$）的连接，**不自动去除同名属性列** | 结果包含两表的所有列 |
| **$\div$** | **除运算 (Division)** | 象集覆盖：求解“同时具有某集合全部属性”的问题（如“选修了全部课程的学生”） | 软考常考象集包含逻辑 |

## 二、 命题题眼与陷阱防御

> [!CAUTION]
> ### 🚨 常见命题陷阱盘点
> 1. **下午题 2 问“该 E-R 图最少可转换为几个关系模式？”**：
>    - 计算公式：**最少关系模式数 = 实体个数 + M:N联系个数**（1:1 和 1:N 联系全部合并入实体端，只有 M:N 联系必须独立建表！）；
>    - 如果存在弱实体或三元 M:N 联系，必须额外计入。
> 2. **自然连接与笛卡尔积元组数计算**：
>    - 若表 $R$ 有 $m$ 个元组，表 $S$ 有 $n$ 个元组，笛卡尔积 $R \times S$ 的元组数必为 $m \times n$ 行；
>    - 自然连接 $\bowtie$ 仅保留公共属性相等的元组，因此元组数必 $\le \min(m \times n, \text{有效匹配数})$，且**结果属性列数为两表属性数之和减去公共属性个数**。
> 3. **投影操作去重特性**：
>    - 纯关系代数的投影 $\pi$ 运算在数学上是集合，**默认自动去重**；而 SQL 语言中的 `SELECT` 默认保留重复项（除非加 `DISTINCT`），出题时经常以去重与否设置陷阱。

## 三、 典型真题溯源与验证

### 【真题精选 1】（考查 E-R 模型向关系模式转换最少数量）
**题干**：某高校教学管理系统中，有“系”、“教师”和“课程”3 个实体。每个系聘用多名教师，每位教师只属于一个系；每门课程由多名教师讲授，每位教师可讲授多门不同的课程。在将该 E-R 图转换为关系模式时，最少可转换为（ ）个关系模式。
A. 3  
B. 4  
C. 5  
D. 6  

**【答案】**：**B**  
**【解析】**：
1. 分析实体及其联系：
   - 实体：系、教师、课程（共 3 个实体）；
   - 联系 1：“系”与“教师”是 1:N 联系（1个系对应多名教师），可直接合并到“教师”模式中（在教师表中加入“系编号”作为外键）；
   - 联系 2：“教师”与“课程”是 M:N 联系（多位教师讲授多门课程），必须单独转换为一个独立的关系模式（讲授模式，主键为教师号+课程号）。
2. 最少关系模式总数 = 3 个实体模式 + 1 个 M:N 联系模式 = 4 个。故选 B。
