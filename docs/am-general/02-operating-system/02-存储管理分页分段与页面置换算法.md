## 一、 核心考纲与概念辨析

### 1. 分页存储管理与地址映射转换

- **页面与物理块**：
  - 进程的逻辑地址空间被等分成若干个大小固定的**页 (Page)**，从 0 开始编号；
  - 内存物理空间被等分成同样大小的若干个**物理块/页框 (Page Frame)**。
- **逻辑地址结构**：
  $$\text{逻辑地址} = (\text{页号 } P, \text{页内偏移 } W)$$
  - 若页面大小为 $4\text{KB} = 4096\text{ 字节} = 2^{12}\text{ 字节}$，则**低 12 位（十六进制低 3 位）**为页内偏移 $W$，其余高位为页号 $P$。
- **地址转换三步法**：
  1. 提取逻辑地址的页号 $P$ 与页内偏移 $W$；
  2. 查**页表**，校验页号是否在有效范围内，读取对应的**物理块号 $B$**；
  3. 物理地址 = 物理块号 $B \times \text{页面大小} + W$（在十六进制下直接将块号拼在偏移高位）。

---

### 2. 页面置换算法全景对比

当进程访问的页面不在内存中且物理块已被占满时，操作系统触发**缺页中断**并选择一页淘汰换出到磁盘对换区：

| 算法名称 | 淘汰策略 | 算法性能与实现复杂度 | Belady 异常 |
| :--- | :--- | :--- | :--- |
| **最佳置换算法 (OPT)** | 淘汰**以后永不使用**或**在未来最长时间内不再被访问**的页面 | 理想化算法，性能最高，但需预知未来，**无法实际实现** | **无** |
| **先进先出算法 (FIFO)**| 淘汰**最早进入内存**的页面（驻留时间最长） | 实现最简单（借助队列），但未考虑访问频率，性能较差 | **有 Belady 异常**（增加物理块数，缺页次数不降反升） |
| **最近最久未使用 (LRU)**| 淘汰**在最近一段时间内最久未被访问**的页面 | 基于时间局部性原理，性能最接近 OPT，利用计数器或堆栈实现 | **无**（属于堆栈类算法） |
| **时钟置换 (CLOCK)** | 为每页设置一位访问位（0或1），循环指针扫描，将 1 置 0，遇 0 淘汰 | 折中优化算法，工程实际广泛采用 | **无** |

### 3. 分段存储 vs 分页存储对比辨析

| 对比维度 | 分页存储管理 (Paging) | 分段存储管理 (Segmentation) |
| :--- | :--- | :--- |
| **信息切分维度** | **一维地址空间**（页内偏移大小固定，系统硬件自动划分） | **二维地址空间**（段长不固定，程序员显式指定逻辑段名） |
| **基本单位大小** | 物理大小固定（通常为 4KB） | 逻辑大小可变，取决于对应程序段（如主函数、数据段）的大小 |
| **设计核心目的** | **提高内存利用率，彻底消除外部碎片**（仅有微量页内内部碎片） | **方便编程、模块化、分段共享与动态链接** |
| **越界中断检查** | 仅检查页号是否超出页表长度 | **检查段号是否越界**，且**必须严格检查段内偏移 $W \ge \text{段长}$**（高频考点） |

## 二、 命题题眼与陷阱防御

> [!CAUTION]
> ### 🚨 常见命题陷阱盘点
> 1. **十六进制地址转换秒杀**：
>    - 题目：页面大小为 4KB，逻辑地址为 `0x2C48`，查页表知 2 号页对应物理块号为 6。
>    - 秒杀法：$4\text{KB} = 2^{12}$，末尾 3 位十六进制 `C48` 为页内偏移；前缀 `2` 为页号；对应块号 6，直接拼接为 `0x6C48`！无需转十进制算半天。
> 2. **缺页中断次数 vs 页面淘汰置换次数**：
>    - 若分配了 3 个物理块，访问序列前 3 个不同页面装入内存产生的缺页**只属于装入缺页**；只有从第 4 个不在内存的页面开始，由于物理块满而把旧页面换出，才产生**页面置换**！
> 3. **Belady 异常的归属**：
>    - 软考常考“下列页面置换算法中，可能出现 Belady 异常的是（ ）”，唯一答案必定是 **FIFO（先进先出）算法**！LRU 和 OPT 均严格证明绝无此异常。
> 4. **页面状态位与修改位**：
>    - 状态位（存在位）：1 表示在内存，0 表示不在内存（访问触发缺页中断）；
>    - 修改位（脏位）：1 表示被写过，淘汰时**必须写回磁盘**；0 表示未被修改，淘汰时直接覆盖，无需写磁盘（磁盘开销为 0）。

## 三、 典型真题溯源与验证

### 【真题精选 1】（考查分页地址转换与页面淘汰）
**题干**：进程 $P$ 的逻辑地址空间被划分为每页大小为 4KB 的页面，其页表部分内容如下表所示。若进程运行时执行到逻辑地址为十六进制 `0x1B2C` 的指令，当该指令访问内存时，其对应的物理内存地址为（ ）。
| 页号 | 物理块号 | 状态位 |
| :---: | :---: | :---: |
| 0 | 5 | 1 |
| 1 | 8 | 1 |
| 2 | 3 | 0 |
A. `0x1B2C`  
B. `0x5B2C`  
C. `0x8B2C`  
D. `0x3B2C`  

**【答案】**：**C**  
**【解析】**：
1. 页面大小为 $4\text{KB} = 4096\text{ 字节} = 2^{12}$ 字节，对应的逻辑地址低 12 位（即十六进制低 3 位 `B2C`）为页内偏移量；
2. 剥离低 3 位后，高位为页号，即页号 $P = 1$；
3. 查页表可知，1 号页在内存中（状态位为 1），其对应的物理块号为 8；
4. 将物理块号 8 与页内偏移 `B2C` 拼接，得到实际物理地址为 `0x8B2C`。故选 C。
