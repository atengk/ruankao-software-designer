## 一、 核心考纲与概念辨析

### 1. 进程状态流转模型（三态 vs 五态）

```
                  时间片用完
         ┌─────────────────────────┐
         │                         │
         ▼     进程调度(获得CPU)    │
     【就绪态】 ────────────────> 【运行态】
         ▲                         │
         │   等待事件发生(如I/O完成) │ 等待事件发生(如申请I/O)
         │                         ▼
         └─────────────────── 【阻塞态/等待态】
```

- **就绪 $\rightarrow$ 运行**：处于就绪队列的进程被进程调度程序选中，获得 CPU 执行权；
- **运行 $\rightarrow$ 就绪**：分配给进程的时间片用完，或出现更高优先级的进程抢占 CPU；
- **运行 $\rightarrow$ 阻塞**：进程因请求某项系统服务（如等待 I/O、申请锁、P 操作资源不足）而主动放弃 CPU；
- **阻塞 $\rightarrow$ 就绪**：等待的外部事件完成（如 I/O 操作结束、V 操作释放资源），进程由等待队列进入就绪队列。
- **🚨 核心禁区**：**不能从“阻塞态”直接转换到“运行态”**（必须先进入就绪态等待调度），**也不能从“就绪态”直接转换到“阻塞态”**！

### 2. 前趋图与 PV 信号量操作模型（必考大题型）

- **信号量 $S$ 的物理意义**：
  - $S \ge 0$ 时：表示系统中当前可用资源的数量；
  - $S < 0$ 时：$|S|$ 表示当前处于该信号量阻塞等待队列中的进程数目。
- **P 操作（申请资源/Wait）**：
  ```c
  S = S - 1;
  if (S < 0) {
      // 资源不足，将当前进程挂起并放入该信号量的等待队列
      block();
  }
  ```
- **V 操作（释放资源/Signal）**：
  ```c
  S = S + 1;
  if (S <= 0) {
      // 说明此前有进程正在排队等待该资源，唤醒等待队列中的一个进程
      wakeup();
  }
  ```

#### 前趋图与信号量标注三步秒杀法
对于前趋图中的每一条有向边 $P_i \rightarrow P_j$：
1. **每条有向边设立一个独立的信号量**（初值均为 0）；
2. **在弧尾节点（前驱活动 $P_i$）执行完毕后，执行 $V(S)$ 释放信号量**；
3. **在弧头节点（后继活动 $P_j$）开始执行前，执行 $P(S)$ 申请信号量**。
- **口诀**：**前 V 后 P，出边为 V，入边为 P！**

### 3. 死锁产生条件与银行家算法

#### ① 死锁产生的四大必要条件（缺一不可）
1. **互斥条件**：资源在一段时间内只能由一个进程独占；
2. **请求与保持条件**：进程已持有至少一个资源，但又提出新的资源请求，且对自身已获得的资源保持不放；
3. **不剥夺条件**：进程已获得的资源在未使用完前不能被其他进程强行抢占；
4. **环路等待条件**：存在一个进程-资源的循环等待链（$P_0$ 等 $P_1$，$P_1$ 等 $P_2 \dots P_n$ 等 $P_0$）。

#### ② 死锁避免：银行家算法 (Banker's Algorithm)
- 核心矩阵关系：$\text{需求矩阵 } Need[i][j] = \text{最大需求 } Max[i][j] - \text{已分配 } Allocation[i][j]$；
- **安全性检查算法**：寻找是否存在一个**安全执行序列**（每个进程的剩余需求 $Need$ 均小于等于系统当前的可用资源 $Available$），若存在至少一个安全序列，则系统处于安全状态，绝不发生死锁。

#### ③ 资源分配防死锁最值公式
若系统中有 $m$ 个同类不可剥夺资源，被 $n$ 个并发进程共享，每个进程最多需要 $k$ 个资源。则**系统绝不发生死锁的充分必要条件**为：
$$m \ge n \cdot (k - 1) + 1$$
*(极值推导：最极端恶劣情况下，每个进程都已分得 $k-1$ 个资源且均在等待最后 1 个，此时只要系统多出 1 个资源，就能使其中一个进程顺利完成并释放全部资源，打破僵局)*。

## 二、 命题题眼与陷阱防御

> [!CAUTION]
> ### 🚨 常见命题陷阱盘点
> 1. **前趋图出入边识别**：
>    - 某进程若有 3 条入边，则该进程开头必须执行 3 次独立的 P 操作；若有 2 条出边，则该进程末尾必须执行 2 次独立的 V 操作。数清入边和出边即可 100% 秒杀！
> 2. **死锁“预防” vs “避免” vs “检测”区分**：
>    - **死锁预防**：通过破坏死锁的四个必要条件之一（如静态资源一次性分配破坏请求与保持，资源编号顺序分配破坏环路）；
>    - **死锁避免**：在动态分配资源前进行安全评估，典型代表是**银行家算法**；
>    - **死锁解除**：剥夺资源或撤销杀死死锁进程。
> 3. **极值资源公式套用**：
>    - 题目问“有 5 个进程，每个进程需要 3 台打印机，系统至少配备多少台打印机才能保证不死锁？” $\rightarrow m \ge 5 \times (3 - 1) + 1 = 11$ 台！

## 三、 典型真题溯源与验证

### 【真题精选 1】（考查前趋图信号量 PV 操作）
**题干**：某前趋图如下所示，进程 $P_1$ 执行完成后进程 $P_2$ 和 $P_3$ 方可执行；进程 $P_2$ 和 $P_3$ 执行完成后进程 $P_4$ 方可执行。若设置信号量 $S_{12}, S_{13}, S_{24}, S_{34}$，且初值均为 0。则在进程 $P_1$ 的末尾和进程 $P_4$ 的开头应分别执行的 PV 操作为（ ）。
A. $V(S_{12}), V(S_{13})$；$P(S_{24}), P(S_{34})$  
B. $P(S_{12}), P(S_{13})$；$V(S_{24}), V(S_{34})$  
C. $V(S_{12}), P(S_{13})$；$V(S_{24}), P(S_{34})$  
D. $P(S_{12}), V(S_{13})$；$P(S_{24}), V(S_{34})$  

**【答案】**：**A**  
**【解析】**：
套用“出边为 V，入边为 P”法则：
- $P_1$ 有两条发出的出边（指向 $P_2$ 和 $P_3$），在完成时必须分别通知这两个进程，故应执行 $V(S_{12})$ 和 $V(S_{13})$；
- $P_4$ 有两条汇入的入边（来自 $P_2$ 和 $P_3$），在开始执行前必须等待这两个进程都完成，故应执行 $P(S_{24})$ 和 $P(S_{34})$。选 A。

### 【真题精选 2】（考查并发防死锁资源临界值）
**题干**：某计算机系统中共有 3 个并发进程分别竞争同类型的共享资源，每个进程最大需要占用 4 个该类资源。为了确保该系统永远不会发生死锁，系统至少需要配置该类资源（ ）个。
A. 9  
B. 10  
C. 11  
D. 12  

**【答案】**：**B**  
**【解析】**：
直接套用防死锁极值公式：
$$m \ge n \cdot (k - 1) + 1 = 3 \times (4 - 1) + 1 = 3 \times 3 + 1 = 10$$
当资源为 9 个时，若每个进程各占 3 个，系统剩余资源为 0，每个进程都在等待第 4 个资源，将发生死锁；一旦系统拥有 10 个资源，无论如何分配，至少会有 1 个进程能分到第 4 个资源得以执行完毕，释放全部 4 个资源供给后续进程。故选 B。
