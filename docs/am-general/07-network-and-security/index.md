# MOD-07 网络与信息安全专题

- **考纲地位**：综合知识必考 7 ~ 8 分（7 ~ 13 题, 66 ~ 70 题）
- **梯队归属**：第三梯队（网络基础通信与安全密码学）

## 考点精要清单

1. [01-OSI七层模型与TCPIP协议栈协议端口.md](./01-OSI七层模型与TCPIP协议栈协议端口.md)
   - OSI 七层模型、PDU 数据单元与硬件设备（网桥/交换机二层，路由器三层）
   - 常用应用层协议传输层归属与默认端口号速查（DNS 53, DHCP 67/68, HTTP 80, HTTPS 443, FTP 20/21, SMTP 25, POP3 110, SNMP 161）
   - TCP（三次握手/四次挥手、可靠字节流、拥塞控制）vs UDP（无连接、尽力交付）
2. [02-IP地址规划子网划分与CIDR路由聚合.md](./02-IP地址规划子网划分与CIDR路由聚合.md)
   - A/B/C/D/E 类 IP 地址范围与三大专用私网地址段
   - 子网划分与可用主机数计算模型（有效主机数必须减 2：$2^h - 2$）
   - CIDR 无分类路由聚合超网汇聚三步法（最长前缀匹配原则）
3. [03-网络安全加解密算法数字签名与数字信封.md](./03-网络安全加解密算法数字签名与数字信封.md)
   - 对称密码（DES, AES, RC4）vs 非对称公钥密码（RSA, ECC）全景对比
   - 消息摘要算法（MD5 128位, SHA-1 160位, SHA-256）
   - 数字签名十六字秒杀口诀（**“公钥加密私钥解密用于保密通信；私钥签名公钥验签用于防抵赖”**）
   - 数字信封混合加密体制运行流程
