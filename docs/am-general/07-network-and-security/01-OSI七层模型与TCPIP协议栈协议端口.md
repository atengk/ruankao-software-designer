### 2. 常用高频网络应用层协议与默认端口号速查表

> [!IMPORTANT]
> 软考上午选择题极度高频考查以下协议的**传输层协议类型（TCP/UDP）**与**默认知名端口号**：

| 协议名称 | 中文全称 | 底层传输层协议 | 默认端口号 | 核心用途与工作机制 |
| :--- | :--- | :--- | :--- | :--- |
| **DNS** | 域名解析系统 | **UDP / TCP** | **53** | 域名与 IP 地址双向解析（普通查询用 UDP，区域传输用 TCP） |
| **DHCP** | 动态主机配置协议 | **UDP** | **67 (服务端) / 68 (客户端)** | 自动为网络内主机动态分配 IP、子网掩码、网关与 DNS |
| **HTTP** | 超文本传输协议 | **TCP** | **80** | 万维网网页明文传输协议 |
| **HTTPS** | 安全超文本传输协议 | **TCP** | **443** | 基于 SSL/TLS 加密的安全网页传输 |
| **FTP** | 文件传输协议 | **TCP** | **20 (数据连接) / 21 (控制连接)** | 文件上传下载（控制通道发指令，数据通道传文件） |
| **SMTP** | 简单邮件传输协议 | **TCP** | **25** | **发送邮件**从客户端发至邮件服务器 |
| **POP3** | 邮局协议版本3 | **TCP** | **110** | **接收邮件**从邮件服务器拉取至客户端（下载并从服务器删除） |
| **IMAP4** | 互联网邮件访问协议 | **TCP** | **143** | **接收邮件**并支持多端双向同步 |
| **SNMP** | 简单网络管理协议 | **UDP** | **161 (操作) / 162 (Trap告警)**| 网络设备监控与集中配置管理 |
| **Telnet** | 远程终端协议 | **TCP** | **23** | 远程明文登录控制台（不安全） |
| **SSH** | 安全外壳协议 | **TCP** | **22** | 远程加密 Shell 安全登录与传输 |

### 3. TCP 与 UDP 核心机制对比

| 对比维度 | TCP (Transmission Control Protocol) | UDP (User Datagram Protocol) |
| :--- | :--- | :--- |
| **连接状态** | **面向连接**（需经过三次握手建立连接，四次挥手断开连接） | **无连接**（无需建立连接，直接发送数据报） |
| **可靠性** | **可靠交付**（通过序号机制、确认应答 ACK、超时重传保证无差错、不丢失、不重复、按序到达） | **不可靠交付**（尽最大努力交付，不保证按序到达，不重传） |
| **传输模式** | **面向字节流**（将数据视为无结构的字节流，自动分段） | **面向报文**（保留应用层报文边界，不拆分也不合并） |
| **开销与首部** | 首部较长（**最小 20 字节**，最大 60 字节） | 首部极小（**固定 8 字节**），协议开销极低 |
| **流控与拥塞** | 支持滑动窗口流量控制与拥塞控制（慢开始、拥塞避免、快重传、快恢复） | 无拥塞控制，网络拥塞不降低源主机发送速率 |
| **典型应用场景**| 网页浏览 (HTTP/HTTPS)、文件传输 (FTP)、邮件 (SMTP/POP3) | 视频直播、语音电话 (VoIP)、实时网络游戏、DNS 查询 |

## 二、 命题题眼与陷阱防御

> [!CAUTION]
> ### 🚨 常见命题陷阱盘点
> 1. **FTP 的双端口机制**：
>    - 控制连接端口为 **21**（用于账号验证与传送命令，贯穿整个会话）；
>    - 数据连接端口为 **20**（用于传送文件内容，在主动模式 PORT 下使用）。
> 2. **邮件协议的“发”与“收”**：
>    - **发信**协议只有 **SMTP**（25 端口）；
>    - **收信**协议是 **POP3**（110 端口）或 **IMAP**（143 端口）。出题人常将发信说成 POP3 设坑。
> 3. **网络层常用协议的协议号与归属**：
>    - **ARP（地址解析协议）**：功能是将已知的 **IP 地址解析为物理 MAC 地址**，工作在网络层与数据链路层之间（常归为**网络层**）；
>    - **ICMP（网际控制报文协议）**：常用的 `ping` 命令和 `traceroute` 命令就是基于 ICMP 实现的，直接封装在 IP 数据报中。

## 三、 典型真题溯源与验证

### 【真题精选 1】（考查网络协议与端口号匹配）
**题干**：在 Internet 网络应用中，协议和端口号对应关系正确的是（ ）。
A. DNS 使用 TCP 80 端口  
B. SMTP 使用 TCP 110 端口  
C. HTTPS 使用 TCP 443 端口  
D. SNMP 使用 TCP 161 端口  

**【答案】**：**C**  
**【解析】**：
- A 选项 DNS 默认使用 UDP 53 端口；
- B 选项 SMTP 默认使用 TCP 25 端口（110 是 POP3 端口）；
- C 选项 HTTPS（基于 SSL/TLS 的 HTTP）默认使用 TCP 443 端口，完全正确；
- D 选项 SNMP（简单网络管理协议）基于 UDP 协议，使用 UDP 161 端口。故选 C。
