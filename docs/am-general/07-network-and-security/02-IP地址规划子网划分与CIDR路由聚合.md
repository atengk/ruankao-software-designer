### 2. 子网划分与可用主机数计算标准模型

把传统两级 IP 地址（网络号 + 主机号）划分为三级 IP 地址（网络号 + **子网号** + **主机号**）：

- **网络地址**：主机位**全部置为 0** 的地址（代表当前子网自身，不可分配给主机）；
- **直接广播地址**：主机位**全部置为 1** 的地址（向当前子网内所有节点广播，不可分配给主机）；
- **有效可用主机地址范围**：
  $$\text{有效主机数} = 2^{h} - 2$$
  *(其中 $h$ 为划分后剩余的**主机位位数**，必须严格减去全 0 的网络地址和全 1 的广播地址)*。

#### 常用子网掩码与主机数秒杀速查表

| 前缀长度 | 对应子网掩码 | 借用主机位数 | 划分得到子网数 | 剩余主机位 $h$ | **每个子网最大可用主机数** |
| :---: | :--- | :---: | :---: | :---: | :---: |
| `/24` | `255.255.255.0` | 0 | 1 | 8 | $2^8 - 2 = \mathbf{254}$ |
| `/25` | `255.255.255.128` | 1 | 2 | 7 | $2^7 - 2 = \mathbf{126}$ |
| `/26` | `255.255.255.192` | 2 | 4 | 6 | $2^6 - 2 = \mathbf{62}$ |
| `/27` | `255.255.255.224` | 3 | 8 | 5 | $2^5 - 2 = \mathbf{30}$ |
| `/28` | `255.255.255.240` | 4 | 16 | 4 | $2^4 - 2 = \mathbf{14}$ |
| `/29` | `255.255.255.248` | 5 | 32 | 3 | $2^3 - 2 = \mathbf{6}$ |
| `/30` | `255.255.255.252` | 6 | 64 | 2 | $2^2 - 2 = \mathbf{2}$（点对点链路） |

## 二、 分析模型与 CIDR 路由超网聚合

### 1. CIDR 路由汇聚三步法

将多个连续的小子网合并汇聚为一个大路由条目，大幅压缩骨干路由表项：

```
实例目标：将 192.168.16.0/24 到 192.168.19.0/24 汇聚为一个超网

第 1 步：定位差异字节 ──> 第三字节（16 到 19）
第 2 步：展开为 8 位二进制比对
         16:  0 0 0 1 0 0  0 0
         17:  0 0 0 1 0 0  0 1
         18:  0 0 0 1 0 0  1 0
         19:  0 0 0 1 0 0  1 1
              ───────────
第 3 步：提取最长公共前缀
         公共部分: 前 6 位完全相同 (000100)
         汇聚掩码: 16(前两字节) + 6 = 22 位
         汇聚地址: 192.168.16.0/22
```

## 三、 命题题眼与陷阱防御

> [!CAUTION]
> ### 🚨 常见命题陷阱盘点
> 1. **可用主机数务必减 2**：
>    - 计算主机容量时，千万不能直接写 $2^h$！主机号全 0 为网络地址，主机号全 1 为广播地址，这两者绝对不能作为主机 IP 分配，因此**必须 $-2$**。
> 2. **判断两个 IP 是否在同一个子网**：
>    - 秒杀法：将两个 IP 地址分别与子网掩码做**按位与运算 (AND)**，如果计算出的**网络地址完全相同**，则两者处于同一子网，可以直接通过二层通信；否则必须经过网关（路由器）转发。
> 3. **最长前缀匹配原则 (Longest Prefix Match)**：
>    - 当路由器转发数据包时，若路由表中有多个路由条目与目的 IP 地址匹配，路由器**优先选择子网掩码最长（即前缀长度数值最大）**的路由条目转发！

## 四、 典型真题溯源与逐项排错解析 (Distractor Analysis)

### 【真题精选 1】（考查子网划分掩码与可用主机数 · 2023上-上午-Q68~69）
**题干**：某单位分配到一个 C 类地址段 `202.115.12.0/24`，若要将其划分为 4 个大小相等的子网，则每个子网的子网掩码应设置为（ ），每个子网内最多可以容纳的有效可用主机数量为（ ）台。
(1) 
A. `255.255.255.128`  
B. `255.255.255.192`  
C. `255.255.255.224`  
D. `255.255.255.240`  
(2) 
A. 30  
B. 62  
C. 64  
D. 126  

- **【正确答案】**：**(1) B  (2) B**
- **【核心切入点】**：由划分 4 个子网确定借用 2 位主机位，计算新掩码与扣除保留地址后的主机容量。

#### 逐项排错剖析 (Distractor Analysis)
- **第 (1) 空排错**：
  - 划分 4 个子网需满足 $2^k \ge 4 \implies k = 2$；
  - 借用 2 位主机位后，子网掩码前缀变为 $24 + 2 = 26$ 位；
  - 第四字节二进制为 `11000000`，转换为十进制为 $128 + 64 = 192$；
  - 完整掩码为 `255.255.255.192`。
  - **选项 B 正确**；选项 A (128) 仅划分为 2 个子网；选项 C (224) 划分为 8 个子网；选项 D (240) 划分为 16 个子网。
- **第 (2) 空排错**：
  - 剩余主机位数 $h = 32 - 26 = 6$ 位；
  - 每个子网的最大可用主机数必须扣除全 0 和全 1：
    $$N_{\text{有效}} = 2^6 - 2 = 64 - 2 = 62\text{ 台}$$
  - **选项 B 正确**；选项 C (64) 是忘了减去网络地址与广播地址的经典陷阱；选项 A (30) 属于借 3 位的容量；选项 D (126) 属于借 1 位的容量。

### 【真题精选 2】（考查 CIDR 路由超网聚合 · 2022下-上午-Q69）
**题干**：设有 4 个路由条目：`172.16.0.0/24`、`172.16.1.0/24`、`172.16.2.0/24` 和 `172.16.3.0/24`。将这 4 个路由进行汇聚后，生成的超网路由为（ ）。
A. `172.16.0.0/21`  
B. `172.16.0.0/22`  
C. `172.16.0.0/23`  
D. `172.16.1.0/22`  

- **【正确答案】**：**B**
- **【核心切入点】**：将第三字节 0~3 展开为 8 位二进制，求最长公共前缀。

#### 逐项排错剖析 (Distractor Analysis)
- **二进制比对推演**：
  - 0: `0000 0000`
  - 1: `0000 0001`
  - 2: `0000 0010`
  - 3: `0000 0011`
  - 公共高位前缀为前 6 位 `000000`，后 2 位发生变化；
  - 汇聚掩码为 $16 + 6 = 22$ 位；
  - 网络地址第三字节全补 0 得 `0`，即 `172.16.0.0/22`。
- **选项 A (/21) 错误**：/21 会覆盖 8 个 C 类子网（0~7），超出了原有 4 个子网的汇聚边界。
- **选项 B 正确**：精准汇聚 4 个子网，前缀长度为 22 位。
- **选项 C (/23) 错误**：/23 仅能汇聚 2 个子网（0 和 1），无法覆盖 2 和 3。
- **选项 D 错误**：汇聚后的网络地址主机位必须为全 0，不能写成 `172.16.1.0`。
