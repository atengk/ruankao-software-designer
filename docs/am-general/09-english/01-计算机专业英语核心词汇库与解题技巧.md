## 三、 软考专业英语三大解题绝技

1. **“上下文同位语与关系代词”定位法**：
   - 英文科技文中，生词后面紧跟的定语从句（`which...`、`that...`）或同位语（`, or...`）通常就是该术语的标准定义！
   - *例*：`A design pattern (71) a general repeatable solution to a commonly occurring problem...` $\rightarrow$ 显然填 `provides` 或 `is`。
2. **“软考高频词直接选”原则**：
   - 当遇到软件设计原则题目时，选项中如果出现 `loose coupling`（松散耦合）、`high cohesion`（高内聚）、`information hiding`（信息隐藏），极大概率是正确选项！
3. **“因果转折连词”逻辑验证法**：
   - 遇到转折连词 `however`, `although`, `whereas`，挖空前后词义必定**相反**；遇到并列连词 `and`, `as well as`, `furthermore`，挖空前后词义必定**同向**。

## 四、 典型真题溯源与验证

### 【真题精选】（面向对象与设计模式英文综合题）
**Passage**：
In software engineering, a design pattern is a general repeatable solution to a commonly occurring problem in software design. It is not a finished design that can be transformed directly into code. Rather, it is a description or template for how to solve a problem that can be used in many different situations. 

Object-oriented design patterns typically show (71) and interactions between classes or objects, without specifying the final application classes or objects that are involved. Patterns that imply mutable state may be unsuited for functional programming languages.

One of the most important benefits of design patterns is that they can speed up the development process by providing tested, proven development paradigms. Effective software design requires considering issues that may not become visible until later in the implementation. Reusing design patterns helps to prevent subtle issues that can cause major problems, and it improves code (72) for coders and architects who are familiar with the patterns.

(71) A. relationships  B. algorithms  C. hardware  D. databases  
(72) A. complexity  B. readability  C. cost  D. length  

**【答案】**：**(71) A  (72) B**  
**【解析】**：
- (71) 题考查面向对象设计模式所展示的内容：设计模式通常展示类和对象之间的**相互关系 (relationships)** 与动态交互，因此选 A；
- (72) 题考查使用设计模式的好处：复用设计模式不仅能够防范潜在隐患，还能显著提高代码的**可读性 (readability)**，便于熟悉这些模式的程序员和架构师理解维护，因此选 B（不可能提高复杂度 complexity 或长度 length）。
