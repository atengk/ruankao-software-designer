# 规格说明：上午综合知识科目深化、题库与公式速查表建设

分诊标签: `ready-for-agent`

## 问题陈述 (Problem Statement)

备考 2026 年下半年全国计算机技术与软件专业技术资格（水平）考试 —— 软件设计师（中级）的考生在备考上午综合知识（75分单选题）时，面临以下痛点：
1. **知其然不知其所以然**：传统刷题仅核对单选答案，缺乏对错误选项（干扰项）的深度剖析，换个问法容易再次掉入相同陷阱。
2. **机考新法新规脱节**：近年来机考强化了《个人信息保护法》、等保 2.0、现代敏捷软件工程（Scrum/看板）、云原生微服务术语的考核，而传统讲义未及时覆盖。
3. **计算公式分散易混**：体系结构、操作系统、软件工程、网络等学科涉及数十个重要计算公式，参数物理意义和边界条件容易混淆，考前缺乏高密度集中速查工具。

## 解决方案 (Solution)

在现存 9 大考纲学科 22 篇基础考点精要的基础上，实施系统化深化与题库构建：
1. **深度补充易错陷阱与新规考点**：增补近年新增法规、敏捷过程与微服务术语，深挖易混淆概念。
2. **嵌入式真题切入与逐项排错解析**：在每个考点精要的第四要素中嵌入历年经典真题，严格实施“逐项排错解析（Distractor Analysis）”，对每一个错误选项透彻阐明错误机理与干扰手法。
3. **建立集中式公式速查手册**：集中编制全学科数值计算公式速查表，明确公式推导、参数意义、速算口诀与极限边界。
4. **四梯队工单化推进**：按投产比将 9 大学科拆解为 4 张 Epic 工单，支持分批次 `/implement` 高质量交付。

## 用户故事 (User Stories)

3. 作为一个备考软件设计师的考生，我期望在练习“Cache 与主存映射”真题时，每个选项都有详细的排错理由，以便于弄清全相联、直接映射和组相联的本质区别。

## 实现决策 (Implementation Decisions)

1. **学科知识库组织边界与结构扩充**：
   - 保持现有 9 个一级学科目录划分（`01-computer-architecture` 到 `09-english`）；
   - 对现有 22 篇 Markdown 考点精要进行原位增强，确保每个文档严格满足“四要素闭环”；
   - 在各学科内按需补充新考纲概念章节（如网络安全新法规、敏捷工程进阶等）。

2. **嵌入式真题排版与逐项排错解析规范**：
   - 每篇考点精要第四部分至少精选 2~4 道最具代表性的历年真题；
   - 真题必须注明准确溯源编号（如 `2023下-上午-Q32`）；
   - 题解排版统一规范：
     - 正确答案与核心解题切入点；
     - **逐项排错剖析**：对 A、B、C、D 四个选项分别展开深度点评，指出错误原因、概念混淆点或纠正后的正确表述。

3. **集中式公式速查手册架构设计**：
   - 在上午题根目录新建独立的公式速查文件；
   - 按学科分类编排，统一采用表格与 KaTeX 公式渲染；
   - 表格字段统一为：**考点模块**、**核心公式 / 换算关系**、**变量物理意义**、**速算口诀与极限边界**、**典型真题考法**。

4. **看板索引与全局导航升级**：
   - 更新上午题全局导航看板，置顶公式速查手册跳转入口；
   - 标注各考点精要的题库嵌入状态与真题数量，形成全景进度视图。

## 验证与验收接缝 (Testing Decisions)

1. **结构与四要素闭环验收接缝**：
   - 验证所有增强后的考点精要文档是否 100% 具备四大标准章节标题（核心考纲、公式模型、命题陷阱、典型真题）；
   - 严禁出现只有知识点总结而无典型真题验算的半成品文档。

2. **逐项排错解析深度验收接缝**：
   - 验证每一道嵌入真题是否对所有未入选选项提供了明确的错误判定理由；
   - 严禁出现仅标注“B 选项错误，因为概念不符”的敷衍解析，必须指出其正确概念或适用场景。

3. **公式速查表完整性与无死角验收接缝**：
   - 验证全科核心计算（流水线、Cache、海明码、PV 操作前趋、分页地址、磁盘寻道、环路复杂度、PERT 关键路径、二叉树、子网掩码）是否全部收录在公式速查表中；
   - 验证公式中符号含义是否自解释无歧义。

4. **全域中文本地化与排版验收接缝**：
   - 严格通过全域汉化门禁，所有标题、说明、解析均使用自然清晰中文；
   - 数学公式与符号正确使用 KaTeX 语法（单 `$` 或双 `$$`），Windows 超链接采用正斜杠 `file:///` 格式。

## 范围外声明 (Out of Scope)

1. **下午应用技术科目（75分）大题解析**：数据流图 DFD、数据库设计 E-R/SQL、UML 建模分析、C 语言算法及 Java 设计模式填空不属于本上午题规格范围，由后续下午题专项规格独立承载。
2. **源码级 Java 21 工程脚手架搭建**：面向对象设计模式与算法的单元测试实操工程属于后续实操验证阶段，不在本规格中落地。
3. **整套模拟卷机考模考系统开发**：不涉及在线答题 Web 系统或交互软件开发，所有交付物以高质量本地 Markdown 知识库与题库形式组织。

## 补充说明 (Further Notes)

本规格说明发布后，将通过 `/to-tickets` 按 4 大梯队拆解为 4 张独立的工程工单（Issues），各工单之间按投产比高低顺序依赖，支持逐个执行 `/implement` 渐进式交付。
